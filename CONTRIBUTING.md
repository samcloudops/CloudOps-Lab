# Contributing to CloudOps-Lab

Thank you for your interest in this repository.

## Contribution Guidelines

1. Keep documentation clear and technically accurate.
2. Use descriptive file names.
3. Include examples where useful.
4. Explain commands and their expected results.
5. Never commit passwords, API keys or private credentials.
6. Test scripts before submitting changes.

## Workflow

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test your changes.
5. Submit a pull request.

Let's learn and build responsibly.
