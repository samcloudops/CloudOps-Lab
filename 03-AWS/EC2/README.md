# AWS EC2 - Elastic Compute Cloud

## Overview

Amazon EC2 provides scalable virtual computing capacity
in the AWS Cloud.

## Key Concepts

- AMI: Amazon Machine Image
- Instance Type: Compute and memory configuration
- EBS: Persistent block storage
- Security Group: Virtual firewall
- Key Pair: Instance authentication
- Elastic IP: Static public IPv4 address

## Learning Objectives

1. Understand virtual machine concepts.
2. Study EC2 instance types.
3. Understand security groups.
4. Learn storage fundamentals.
5. Explore instance monitoring.

## Cost Awareness

EC2 resources may generate charges.
Check pricing and estimated costs before launching
resources. Stop or delete resources when no longer needed.

This document is educational, not a deployment guide.
