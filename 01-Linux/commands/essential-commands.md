# Linux Essential Commands

## Navigation

| Command | Purpose |
|---|---|
| pwd | Current directory |
| ls -la | List files |
| cd | Change directory |
| tree | Display directory structure |

## File Management

| Command | Purpose |
|---|---|
| touch | Create file |
| mkdir | Create directory |
| cp | Copy files |
| mv | Move or rename files |
| cat | Display file content |

## System Monitoring

| Command | Purpose |
|---|---|
| uptime | System uptime |
| df -h | Disk usage |
| free -h | Memory usage |
| top | Process monitoring |
| uname -a | System information |
| ps aux | Running processes |

## Networking

| Command | Purpose |
|---|---|
| ip addr | Network interfaces |
| ping | Connectivity testing |
| ss -tuln | Listening sockets |
| curl -I | HTTP response headers |
| getent hosts example.com | DNS lookup |

Commands and available options may differ between Linux distributions.
